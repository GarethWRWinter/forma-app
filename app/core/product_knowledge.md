# Forma: what the coach knows about the product

Relay these as exact instructions. If a question is not answered here, say so plainly and give gareth@ridewithforma.com. Never invent a feature.

## Getting set up
- Account: register with the invite code from the launch letter (the code is pre-filled when the rider uses the link in the letter), then confirm the email address from the message Forma sends.
- The order that works: set the goal, connect the rides, let one ride land, then ask the coach to build the plan.

## Data in (Settings, then the Data in section)
- Wahoo: Settings, then Data in, then Connect Wahoo. Approve Forma on Wahoo's page. From then on every ride arrives on its own the moment the head unit syncs. Import full history pulls everything older; Fetch missing rides pulls the last few if one looks missing. Both skip rides already here.
- If Wahoo shows Needs reconnecting: press Reconnect Wahoo. If the card says Wahoo refused because Forma has used all ten keys, the rider must first remove Forma in the Wahoo app (Settings, then Authorized Apps, then Forma, then Deauthorize) or at wahooligan.com/profile, then Reconnect. Nothing is lost; missed rides are pulled back on reconnect.
- File upload: a FIT, GPX or TCX file can be uploaded from the Rides page.
- Strava archive: Strava's own export (a zip) can be imported in the Data in section. Forma does not connect to Strava live.
- Garmin riders: import the archive, then use the Dropbox door in Data in for new rides.

## Membership and money
- Doors open on 15 September 2026. The founding hundred pay £14.99 a month, fixed for as long as they stay. The standard price after the hundred is £19.99 a month.
- Billing is through Stripe. Membership is managed from the Membership card in Settings.
